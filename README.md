# Web and GitHub Foundations

This repository contains my early hands-on practice with HTML, CSS, Markdown, Git, and GitHub.

I created this work while learning how to build a simple webpage, format documentation, work with images, and connect local files to a public GitHub repository.

## Purpose

The purpose of this repository is to document my technical foundations and show the beginning of my development journey.

Rather than deleting my early practice, I am preserving and improving it to demonstrate continuous learning and professional growth.

## Skills Practiced

- HTML page structure
- CSS styling
- Responsive design
- Markdown formatting
- Tables and lists
- Hyperlinks and images
- Git version control
- GitHub repository management

## Files

- `index.html` — a simple responsive webpage
- `Markdown.md` — Markdown formatting practice
- `Palo_Alto_Lake.jpg` — a personal photograph used in the Markdown example
